Replication : Finance and Green Growth

This repository contains the Stata code used to replicate the results of "Finance and Green Growth"(De Haas and Popov, 2023).

The repository is organised into two folders:

Replication_Total : Contains the full replication code provided by the original authors, which I ran to reproduce their results before preparing my presentation.

Replication_DS : Contains the code used specifically for my presentation, focusing on selected tables from the original paper and an additional extension.

Stata data files are excluded from this repository.
